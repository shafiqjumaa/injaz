# Injaz | إنجاز

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا (Public) على GitHub، مثلًا `injaz`.
2. ارفع الملفات: `index.html` و `.nojekyll`.
3. من Settings ثم Pages: اختر Branch = main والمجلد / (root) ثم Save.
4. بعد دقيقة يظهر الرابط: https://USERNAME.github.io/injaz/

## مفتاح الذكاء الاصطناعي
- لا تضع المفتاح داخل الكود أبدًا (المستودع عام).
- افتح الموقع، ثم أسفل الصفحة: «نسخ احتياطي للبيانات»، والصق مفتاح Groq في الخانة.
- يُحفظ المفتاح في متصفحك فقط.
